# HopeTex Platform

Premium global company formation SaaS — Next.js 15, Tailwind v4, shadcn/ui, Framer Motion.

## Status

**Phase 1 complete:** design system, application shell, navigation, mega menu, footer, templates, pricing UI, service form wizard, dashboard shell.

**Phase 2 pending:** content pages from `/content` markdown.

See [ARCHITECTURE.md](./ARCHITECTURE.md) for full system documentation.

## Quick start

```bash
npm install
npm run dev
```

- Shell preview: http://localhost:3000
- Dashboard shell: http://localhost:3000/dashboard

## Content

Markdown in `/content` is the source of truth for copy, services, packages, FAQs, and legal pages.
